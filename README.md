# Banking Analytics Dashboard

An interactive **Banking Analytics Dashboard** built with **Power BI** to help management understand customer behavior, account performance, transaction activities, loan portfolio status, and customer support performance.

## Project Overview

This project was developed as an end-to-end Business Intelligence solution using banking datasets.  
The dashboard focuses on transforming raw operational data into meaningful insights and actionable recommendations.

The report was designed to answer important business questions across five core areas:

- Executive Overview
- Customer Analysis
- Transaction Analysis
- Loan Analysis
- Customer Support Analysis

## Objectives

The main objectives of this project were to:

- Analyze customer behavior and engagement
- Evaluate account performance and ownership distribution
- Monitor transaction activity and trends
- Understand loan portfolio performance and maturity
- Assess customer support efficiency and issue resolution
- Deliver interactive insights to support better decision-making

## Key Insights

Some important insights identified from the dashboard:

- Transaction volume is high, indicating strong financial activity across the customer base.
- Customer participation in transactions is moderate, meaning not all customers are fully active.
- Accounts are relatively balanced across account types.
- Loan distribution is concentrated in a few loan categories.
- Loan maturity amounts peak in certain future years, which may require planning for repayment monitoring.
- A noticeable number of customers hold cards and loans, showing product adoption opportunities.
- Support resolution rate indicates room for operational improvement.
- Certain customers and issue types contribute more heavily to support workload.

## Business Recommendations

Based on the analysis, the following recommendations can support decision-making:

1. **Increase customer engagement**
   - Target inactive customers with personalized banking offers and awareness campaigns.

2. **Improve support resolution**
   - Investigate unresolved support cases and reduce resolution delays.

3. **Promote cross-selling**
   - Offer loans and cards to customers who have accounts but low product adoption.

4. **Monitor transaction behavior**
   - Review accounts with unusually high or low transaction activity for business and operational insights.

5. **Enhance loan portfolio management**
   - Track high-maturity periods and monitor repayment-related risk proactively.
